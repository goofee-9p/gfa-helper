# GFA 소재 세팅 자동화 툴

네이버 GFA(성과형 디스플레이 광고) 소재 등록 화면을 사람 대신 조작해 주는 **브라우저 내 RPA(UI 자동화) 크롬 확장 프로그램**입니다.

API를 호출하는 방식이 아니라, 실제 사용자가 하는 클릭·입력·파일 업로드를 DOM 이벤트 수준에서 그대로 재현합니다. 비공식 API를 쓰지 않으므로 GFA의 권한·유효성 검증을 정상 경로로 통과합니다.

## 동작 방식 (3계층 구조)

```
사이드패널 (입력·조립) → 백그라운드 워커 (오케스트레이션) → 콘텐츠 스크립트 (화면 자동 조작)
```

1. **사이드패널** ([sidepanel.js](sidepanel.js)) — 프로모션명·코드·랜딩 URL·목적·타겟·이미지를 입력받아 소재 데이터를 일괄 생성합니다.
   - 소재명 자동 조립: `{프로모션명}_{목적}_{타겟}_{지면}_{혜택}_{번호}`
   - 추적 파라미터 자동 부착: `nt_source` / `nt_medium` / `nt_detail` / `nt_keyword`
   - 이미지 규격(픽셀·용량) 사전 검증 및 파일명 기반 슬롯 자동 매칭

2. **백그라운드 서비스 워커** ([background.js](background.js)) — 소재 1개당 GFA 등록 페이지 탭을 하나씩 엽니다.
   - 소재 데이터를 JSON → base64url로 인코딩해 **URL 해시(`#gfa=...`)로 전달** (해시는 서버로 전송되지 않음)
   - 이미지는 메모리에 보관 후 각 탭 요청 시 전달
   - 자동입력이 끝난 만큼만 다음 탭을 여는 **웨이브 방식** (동시 3개) — 뒤쪽 탭이 백그라운드에서 오래 대기하다 크롬 타이머 스로틀링에 걸리는 것을 방지
   - **이미지 업로드는 배치 전체에서 한 번에 하나만** — GFA 이미지 보관함이 계정 공유라 동시에 올리면 서로의 이미지를 집어감

3. **콘텐츠 스크립트** ([content.js](content.js)) — 열린 탭에서 해시를 디코딩해 폼을 자동으로 채웁니다.
   - 소재 유형 칩 정리 → 텍스트/URL 입력 → 이미지 업로드 → 프로필 이미지 선택 → CTA 설정 → 전 항목 재검증
   - 업로드한 이미지는 **파일명으로 대조**해 보관함에서 찾고, 폼에 실제로 붙었는지까지 확인 (실패 시 3회 재시도)
   - 저장 직전에 모든 값을 다시 확인해 비어 있으면 채우고, 그래도 비면 **저장하지 않고 사유를 보고**

## 지원 지면

- **네이티브 광고그룹** — 기본(1250×560) / 피드형(1200×628) / 스퀘어형(1200×1200) / 피드형 2:3(1200×1800), 소재 8개 일괄 생성
- **네이티브 배너형** — 342×228, 소재 유형을 배너형(모바일)+배너형(PC)로 맞추고 설명 문구·PC 긴 설명문구까지 입력 (네이티브 탭에서 켜고 끔, 소재 2개 추가)
- **스마트채널** — 750×280 / 750×160, 혜택별 개수 지정 (로컬 HTML 에디터에서 캔버스 이미지 직접 가져오기 지원)
- **쇼핑프로모션** — 750×500, 이미지 2개 입력 → GFA가 PC/모바일 자동 분할

## 사용 흐름

1. 사이드패널에 프로모션 정보·목적·타겟 입력, 이미지 드래그&드롭
2. GFA 소재 등록 페이지에서 **URL 캡처**
3. **일괄 탭 열기** — 소재별 탭이 열리며 자동 입력 진행
4. 내용 확인 후 **일괄 저장**

## 파일 구성

| 파일 | 역할 |
|---|---|
| [manifest.json](manifest.json) | Manifest V3 확장 정의 |
| [sidepanel.html](sidepanel.html) / [sidepanel.css](sidepanel.css) / [sidepanel.js](sidepanel.js) | 입력 UI·소재 데이터 조립·규격 검증 |
| [background.js](background.js) | 탭 오케스트레이션·이미지 보관·업로드 동시성 제어 |
| [content.js](content.js) | GFA 페이지 DOM 자동 조작 (입력·업로드·다이얼로그 처리) |
